# 📋 Daily Task Checklist App

A simple task checklist application that allows users to create and manage daily tasks. Users can mark tasks as completed and filter tasks by date.

The application uses a **⚛️ React + TypeScript frontend** with **🎨 TailwindCSS** for styling and a **🧱 Laravel backend** with **🗄️ MySQL**. Authentication is implemented using **🔐 JWT stored in HTTP-only cookies**.

---

## ✨ Features

* 🔐 User authentication using **JWT**
* 🍪 Secure authentication using **HTTP-only cookies**
* ➕ Create daily tasks
* ✅ Mark tasks as completed
* 📅 Filter tasks by date
* 🎨 Clean and responsive UI
* 🔗 RESTful API architecture

---
